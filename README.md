# guapi-papeis-api

> Entregar API e regras de negócio completas para avaliação técnica com autenticação e painel administrativo.

## Problema

Entregar API e regras de negócio completas para avaliação técnica com autenticação e painel administrativo.

## Solução

Backend Laravel 9 com PHP 8, Sanctum para autenticação, APIs REST documentadas e Vite para assets do painel — cobrindo CRUD, validações e camadas de serviço.

## Stack

- PHP
- Laravel
- Sanctum
- REST API
